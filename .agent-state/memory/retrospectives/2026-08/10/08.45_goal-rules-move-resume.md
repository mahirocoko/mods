## Architecture Decisions

- Rules are mission-scoped context, not criteria, evidence, blockers, or agent-wide memory.
- A Goal has exactly one conversation owner; continuity is an atomic move, never a copy or shared attachment.
- Origin workspace remains attribution after movement; a normal cross-cwd move warns, while a raw default-lane mismatch fails closed.
- Human acceptance remains human-owned even when Mahiro states the result in natural language; the model tool may record that evidence but cannot convert the criterion to `verified`.
- Existing `/mh-goal` and `mh_update_goal` registrations own the feature to avoid additional reload pressure.

## Lessons Learned

- A real move test should transfer the existing state record; copying or recreating the mission cannot prove single ownership.
- Human messages can be attached as evidence, but human-owned criteria require the human verification surface.
- Stable Rule IDs and workspace attribution are part of continuity evidence, not implementation detail.
- Completion and clear are intentionally distinct: completion preserves the living mission record; clear destroys it.
- Release documentation must be advanced from “pending live evidence” to the exact accepted runtime result before publishing.
